# A trained two-component Mixr inverse

The complete joint-fit feedback adds a roughly similar Boomr+Transfxr laser win and a roughly similar Boomr-only cloth win, but no convincing recreation. Fixed mixture search and joint actual-render search are not neural inversion. This pilot trains directly on mixtures so the encoder can learn component inference. It is one fixed engine pair, not the final all-synth router.

Use actual shipped Mixr with slot0 Boomr and slot1 Transfxr. A temporal two-stream CNN reads frozen whole-sound features; four complete hypotheses predict both source control sets, balance and a categorical structure (Boomr only, Transfxr only, both). Null slots and fixed seeds map back to valid native Mixr patches. Parameter loss masks absent sources and disabled morph controls. Training labels come only from exact generated synth parameters; no rejected, least-bad or roughly similar real clip is treated as a gold control label.

Alternatives deferred: increasing search again would not train component inference; unverified differentiable surrogates already failed actual-render checks; generalizing immediately to all engine pairs would obscure the basic decomposition test. Fixed engines avoid source permutation ambiguity and allow a small proof of concept.

Generate a canonical source bank from the retained certified native parameter corpus, fix random seeds and gain, deduplicate canonical control groups, and split components by stable control hash before pairing. Train, validation and native test must use disjoint components, not merely different pairs of the same sources. Keep sounds between0.08and2.5seconds and finite/audible; this is a short-SFX scope restriction. Native preset families still overlap and older baseline models may know components, so this is not family-independent evaluation. Preserve source bank/control/PCM identities and library/DSP/code hashes.

Train6,144 examples (4,096 mixtures and1,024 of each single engine), validate768 (512+128+128), test96 (64+16+16). Four hypotheses, 60 epochs, batch128, AdamW .001 with cosine schedule, seed20261020; choose lowest validation parameter loss, then evaluate actual DSP. Fixed architecture/loss/budgets are recorded before training. Normalize from training features only and remove peak-gain evidence. No neural checkpoint default is replaced.

Compare four new raw hypotheses with four compositions of frozen independent experts and with actual known source renders. Native diagnostics include all96 test examples, then32 filtered/bit-reduced/resampled native variants as off-distribution diagnostics. External evaluation uses eight archived tagged references from the original off-model batch, with historical best available audio retained; none enters training. Run both frozen audio scorers and retain failure cases. At most8 human trials, majority external, with immediate adequacy in unchanged quick UI. New model failure remains failure; native loss alone cannot establish transfer. Keep original Bfxr available as an external anchor.

Standing user authorization requests autonomous implementation; no additional design permission is needed. Preserve all past feedback and pages and keep work on the existing research worktree.
