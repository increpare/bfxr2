# Chattr implementation plan

**Goal:** A charming, flexible speech synth with text, character voices, and ordinary Bfxr save/export support.

**Architecture:** Pure deterministic speech scheduling and PCM rendering, a SynthBase subclass, and an isolated DOM speech editor. Minimal shared changes add TEXT metadata and preserve strings in share links.

**Tech stack:** Existing browser JavaScript, Web Audio buffers, CSS, Node test runner.

- [x] Add `tests/chattr.test.js`; run `node --test tests/chattr.test.js` and verify missing-feature failures. Cover deterministic bounded PCM, speed/punctuation, blank input, distinctive voices, parameter locks and validation, text/file/link round trips, keyboard focus, and WAV regeneration.
- [x] Create `js/audio/Chattr_DSP.js` and `js/synths/Chattr.js`. Schedule graphemes/digraphs with word and sentence pauses. Render seeded formant, squeak and chip voices. Preserve text across presets/randomization/mutation.
- [x] Add TEXT support to `js/synths/SynthBase.js`, string-safe link encoding in `js/SaveLoad.js`, and editor hooks/typing guards in `js/Tab.js`.
- [x] Create `js/SpeechEditor.js` with textarea, live length, phrase shuffle, Say it/Stop, and audio-clock-driven face animation. Style in `css/index.css`. Register scripts in `index.html` and tab in `js/index.js`.
- [x] Run `npm test`, minify all included scripts with UglifyJS, and check `git diff --check`. Inspect the local browser, exercise typing, presets, play/stop, reload, links, and WAV export. Document controls in README.

Work in the current checkout to retain the user's existing Transfxr changes. Execute inline. Do not commit unrelated work or overwrite generated bin files.
