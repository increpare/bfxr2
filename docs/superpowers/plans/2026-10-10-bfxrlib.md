# Standalone bfxrlib Implementation Plan

> **For agentic workers:** Execute this approved plan inline, task by task, with test-first verification. The existing managed worktree contains the related retired-synth cleanup.

**Goal:** Deliver one redistributable JavaScript file with a global bfxr and no consumer setup.

**Architecture:** Expose PCM rendering on existing engines, bundle those shared sources privately, and add focused modules for portable sound data, bounded caches, and Web Audio voices. Compile Footsteppr patches at build time.

**Tech Stack:** Existing plain JavaScript, Node's test runner and build-time VM, uglify-js, browser Web Audio.
