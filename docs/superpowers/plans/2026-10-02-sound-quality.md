# Sound quality pass

**Goal:** Address the user's listening feedback across the existing cabinet, keeping compact controls and fresh category generators.

**Design:** Preserve existing saves and parameter identities where possible. Add Bfxr's full waveform palette to Transfxr and Chattr without reinterpreting saved numeric values. Retain Chattr's three legacy source recipes as compatible choices. Physical effects should be driven by broadband excitation, contact timing and loss rather than long exposed musical modes. Keep stylized ranges available. Do not alter the praised Swarmr, Zappr or Choirr engines merely to create churn.

**Implementation plan:**
- [x] Root: waveform parity in Transfxr and Chattr, varied Chattr character generation, single-gesture Tappr presets, Notifr timbre variation, discoverable Stackr layering workflow.
- [x] Fracture/blast worker: investigate Fractr and Boomr; replace dominant pitched shard/debris tones with broadband cracking and pressure/debris, preserve all category generators and meaningful controls.
- [x] Contact worker: improve Rustlr friction/folding and Rollr continuous rolling/contact cues, with controls grounded in material and motion.
- [x] Living/string worker: breathing from retro to airy to snoring, investigate Pulser and repair heartbeat behavior, add ordinary and surreal string materials to Pluckr.
- [x] Each worker writes behavioral regressions before changes, verifies deterministic finite bounded raw/output audio, and runs existing relevant tests. No commits, no shared-file changes by workers.
- [x] Root reviews requirements then code, runs full suite and minification, creates a listening collection/reel for changed synths, verifies UI generation and persistence.

**Validation:** Waveform labels cover the current Bfxr menu and remain deterministic. Saved old voice numbers keep their meaning. Category buttons vary multiple relevant controls while respecting locks. Tests measure useful acoustic structure (decay, contact timing, broadband/tonal balance, double beat, finite feedback), rather than claiming numerical checks prove realism. Final subjective sound judgement remains reviewable through rendered examples.

**Results:** 294 tests pass in the full suite; 92 scripts and four stylesheets minify. Browser verifies expanded waveform selectors, repeated Notifr instrument generation, direct copies into Stackr and layer timing surviving reload. Raw-buffer regressions check DSP stability before output conditioning. Independent reviews covered all engine groups and integration; corrected stale button availability on tab activation and individual lock changes. Older positional share links now have explicit field schemas. The listening collection contains 32 editable examples and a 26.51-second reel. These procedural approximations are ready for listening feedback; numerical checks do not establish perceptual realism.
