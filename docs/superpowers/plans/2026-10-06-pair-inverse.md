# Pair inverse implementation plan

**Goal:** Train and test a genuine audio-to-two-component Mixr model, initially Boomr+Transfxr.
**Architecture:** Ordered temporal CNN, four complete patch hypotheses, explicit single/both structure; actual Mixr data and replay. See ../specs/2026-10-06-pair-inverse-design.md for fixed recipe and limitations.
**Tech stack:** Python/Torch/NumPy, existing Node Mixr bridge, buffered quick gallery.

1. Retain complete joint-fit feedback and exact PCM, verify first5 unchanged, extract4new strict heard pairs without duplicating prior labels; keep18qualitative response labels distinct from16 locally audition-supported labels.
2. Implement `tools/neural_invert/pair_model.py` and `tools/tests/test_pair_model.py` with failing tests first. PairCodec provides encode/decode and schema boundaries; PairInverse accepts normalized4083features and returns B×4 hypotheses. Source identities/seeds remain fixed, categorical single/both selection masks absent controls, gradients remain finite. Existing synth/model implementations unchanged.
3. Implement `tools/neural_invert/pair_data.py`. Generate canonical component banks from neural-v2/data-certified-v2; deterministic grouped split by canonical controls;512/128/64 per engine train/val/test pools if available, with explicit failure if insufficient. Mix6,144/768/96 examples as specified, export typed arrays and metadata. Fix seeds .5 and masterVolume .5; use audition PCM consistently. Bind code/DSP/source identities before generation. Verify selected uncached replays and component-disjoint splits.
4. Implement `tools/neural_invert/pair_train.py`. Training-only normalization, ignored gain coordinate,60epochs/batch128/seed20261020, one MPS run. Bind complete dataset/model/code hashes; validate finite loss and record every epoch. Reload best checkpoint and independently reproduce validation loss.
5. Implement immutable experiment script under `tools/multisynth/evaluations/pair-inverse-v1.py` for frozen native and external evaluations. Four proposals for both trained pair and independent expert composition. Preserve every actual candidate, hash and score; verify final native replays. External refinement gets equal budgets and retains old archived candidates; no source audio layers or invented feedback.
6. Review spec compliance then code quality. Execute data, training, native/off-model evaluation. Publish only a concrete useful diagnostic batch, at most8 trials and primarily external. Exact reference and earlier clips, max3 options, native replay, frozen bindings, served-file hashes and no fabricated audition telemetry. Preserve unpromoted failures honestly. Update docs and commit own files.

Tests: codec roundtrip for both and each singleton, categorical bounds, inactive-source loss invariance, deterministic finite model forward/backward, disjoint component identity, train-only normalization and strict checkpoint bindings; existing composition/quick-feedback tests. Do not retrain or re-export old checkpoints/pages.
