# Neural v2 quick listening feedback

The original schema-3 export is retained byte-for-byte in `feedback.json`.
The manifest and 24 lossless FLAC files preserve the five references and 20
candidate identities independently of ignored runs. All presented options were
heard: four relative best choices and one explicit rejection.

`qualitative-assessment.json` separately preserves the accompanying user message:
“we're so far away - only one charm2.wav was actually approximated”. That winner
is the previous Transfxr audio. The two selected Bfxr wins mean relative
preference only; no absolute likeness scores are inferred. Seven strict pairs
from four reference PCM groups are usable for preference training, but they do
not establish a successful v2 approximation.

See `../../evaluations/neural-v2-quick-01-human-review.json` for the audit.
